## Steps

1. `grep -rlE 'from "antd|@ant-design/icons' packages/app` prints nothing. If it doesn't, finish those files first.
2. Remove `antd` and `@ant-design/icons` from `packages/app/package.json`, then run `yarn install`. Don't use `yarn remove`: it re-resolves unrelated packages.
3. `_app.tsx`: delete `import "antd/dist/antd.css"`.
4. `styles/global.css`: delete the `.ant-…` rules. `grep -rn "\.ant-" packages/app` must print nothing.
5. `tailwind.config.js`: remove `corePlugins: { preflight: false }`. Then delete the "Mini reset" block in `styles/tailwind.css`. The antd workarounds in `components/ui` are optional to remove (they're harmless): `m-0 list-none p-0` and `text-foreground` in `pagination.tsx`, and `m-0` / `mt-0` on `DialogTitle`, `AlertDialogTitle`, `SheetTitle` and `AlertTitle`.
6. Run `yarn tsc`, `yarn lint` and `yarn build`, run the smoke test as all 3 roles, check Cypress 31/31, and compare screenshots of every page.

## Done when

- antd is gone from `package.json` and `yarn.lock`.
- All checks pass.
- Merged into `dev`.
