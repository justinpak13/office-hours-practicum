## What it changes

1. **Setup.**
   - Tailwind 3.4 with its reset (preflight) **off**, because it restyles antd. A small `:where()` reset in `styles/tailwind.css` gives shadcn what it needs.
   - The theme's primary color is the app's brand blue, `#3684c6`.
   - **30 components** in `components/ui/` cover every antd component the app uses.
   - `<Toaster />` and `<TooltipProvider>` are in `_app.tsx`.
   - The `@/` import alias and `components.json`, so `npx shadcn@latest add <name>` works.
   - Transpiles `@radix-ui/react-collection` (Next 12's minifier can't read it).
   - Prettier 2.4 → 2.8.8 (2.4 can't parse shadcn's `import { type X }`, so the commit hook would fail).
   - `react/prop-types` lint is off for `components/ui`.
   - Changes to the generated components: `DialogContent` gets a `hideClose` prop; pagination and titles get fixes for antd's global CSS; the Toaster is light-only (shadcn's follows the OS dark mode).
2. **Reference conversion:** `ProfileSettings.tsx` goes from antd Form to shadcn Form (react-hook-form + zod).
   - The same fields, validation rule, messages and `data-cy` hooks. The success message is now a toast.
   - A failed save now shows an error and rolls back.
   - It also fixes a bug that's already on `dev`: `SettingsPage.tsx` remounted the settings forms on every render, which wiped unsaved typing whenever the profile refreshed (for example, after a photo upload).
