## What it changes

- `.nvmrc` = 22; root `package.json` requires Node ≥22.12; CI uses Node 22; DEVELOPING.md updated.
- TypeScript 5.9 in all four packages. One type error fixed in `utils/urlB64ToUint8Array.ts`.
- `bcrypt` 6 (server), `@types/node` 22.
- `typescript-eslint` 4.0.1 → 5.62 (the old one reported 365 false errors on TypeScript 5.9).
- `infrastructure/dev/devProxy.js` uses `127.0.0.1`: on Node 17+, "localhost" goes to IPv6 first and every API call through port 3000 timed out.
- The app's scripts add `NODE_OPTIONS=--openssl-legacy-provider` (Next 10 needs it on modern Node). OH-06 removes it.

Why not Node 24: three server packages (`@nestjs/typeorm` 7, `@nestjs/config` 0.5, `@nestjs/schedule` 0.4) call functions Node 23 removed. Node 24 comes in phase 3.

## Commit, push and open the pull request

```bash
git add -A
git commit --no-verify -m "OH-04: Node 22, TypeScript 5.9, bcrypt 6, typescript-eslint 5.62, dev proxy on IPv4"
git push -u origin oh-04-node-22
```

`--no-verify` skips the repo's automatic formatter for this one commit. That keeps your code identical to the tested version, so the next ticket's commit still copies cleanly. Formatting gets its own step in phase 3.

On GitHub, click **Compare & pull request**. **Check the base before you click Create:** it must be **base repository `justinpak13/office-hours-practicum`** and **base `dev`**. GitHub pre-selects the original Khoury repo on forks, which would send your PR to the maintainers.

Fill in the PR template; paste your check results under "How Has This Been Tested?". Add your reviewer.
