5. As the TA, help the student, then finish the question.

7. Log in as the professor (user 5). Under **Admin Panel**, the check-in calendar shows events.
8. The **Schedule** page shows a calendar.

## Commit, push and open the pull request

```bash
git add -A
git commit --no-verify -m "OH-05: antd 4.24.16 and @ant-design/icons 4.8.3"
git push -u origin oh-05-antd
```

`--no-verify` skips the repo's automatic formatter for this one commit. That keeps your code identical to the tested version, so the next ticket's commit still copies cleanly. Formatting gets its own step in phase 3.

On GitHub, click **Compare & pull request**. **Check the base before you click Create:** it must be **base repository `justinpak13/office-hours-practicum`** and **base `dev`**. GitHub pre-selects the original Khoury repo on forks, which would send your PR to the maintainers.

Fill in the PR template; paste your check results under "How Has This Been Tested?". Add your reviewer.

## If something goes wrong

- `CONFLICT` during cherry-pick: run `git reset --hard` and `git checkout dev`, make sure the previous ticket is merged and you pulled, then start again.
- A check fails or a page looks different: don't merge. Open the PR as a **draft**, paste the error, and post in the team chat.
- "The engine node is incompatible": run `nvm use`.
