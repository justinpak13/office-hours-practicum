## Part A: fix the backend branch (do now)

**What's wrong, and the fix for each:**

1. **The server crashes on startup:** `Cannot find package '@nestjs/common' imported from .../@nestjs/cache-manager/dist/cache.module-definition.js`.
   - `@nestjs/cache-manager` was added to `packages/common/package.json`, the shared package the frontend also uses. Yarn therefore installs it at the root, where it can't see the server's copy of `@nestjs/common`.
   - Fix: remove it from `packages/common`. In `packages/common/index.ts`, import the type with `import type { Cache } from "cache-manager";` (how the original code did it).
2. **Wrong versions for NestJS 11.** `@nestjs/config` 12 and `@nestjs/cache-manager` 12 are the releases for NestJS 12, and they ship only as ES modules. The integration tests can't load them, so 8 of 9 test files fail to start.
   - Fix: use the NestJS 11 versions, `"@nestjs/config": "^4.0.4"` and `"@nestjs/cache-manager": "^3.1.3"`.
3. **Seed "fill queue" creates new courses instead of filling the existing queue.** In `seed.controller.ts`, `await QueueModel.find({ take: 1 })[0]` is always `undefined`, because `[0]` is applied before the `await`. This is why live updates looked broken in smoke tests.
   - Fix: `const [queue] = await QueueModel.find({ take: 1 });`
4. **The alerts endpoint returns 500:** `Property "insights" was not found in "UserModel"`. `alerts.controller.ts` passes the whole `user` object in `where`, and TypeORM 0.3 tries to match every one of its fields.
   - Fix: `userId: user.id`.

**Still open on the backend branch (not fixed by Part A):**

- **`ADMIN_SESSION_SECRET must be set` on startup in development.** `admin/admin-session.ts` reads the setting before `.env.development` is loaded. Workaround: run `set -a; . packages/server/.env.development; set +a` before `yarn dev`. Fix: read the secret inside a function called after config has loaded.
- **About 40 integration tests fail**, from the TypeORM 0.3 move. The usual causes: lookups now return `null` instead of `undefined` (8 tests), snapshots need re-recording (14), and `Cannot read properties of undefined (reading 'catch')` (13). Original code: 98 of 116 pass; this branch: 75–76.
